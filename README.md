# ワークアウトログ（PWA）

自宅筋トレの記録アプリ。Museのスペース版ワークアウトログを、単体で動くPWAとして移植したもの。

## ルール（スペース版から引き継ぎ）

- 器具は腹筋ローラー・プッシュアップバー・ゴムチューブ（＋自重）のみ。**脚の種目は入れない**（マラソンのタイムを落とさないため）
- 週3回・1回30分、A（胸＋三頭）→ B（腕＋肩）→ C（胸＋腹）のローテーション。曜日固定なし
- 進行ルール：全セット目標クリア＆RPE7以下で次回 **+1回**（秒数の種目は **+5秒**）。RPE9以上か回数未達なら据え置き
- 各セッションで「脚の疲労感（1〜5）」と「次のランの感覚」を記録し、ランへの影響を見る

## データの置き場所

- 記録は**端末のブラウザ内（localStorage）だけ**に保存される。このリポジトリにもサーバーにも送られない
- そのため、機種変更・ブラウザのデータ消去で消える。設定画面から **JSONで書き出し／読み込み** ができるので、ときどき書き出して手元（Obsidianのリポジトリ等）に保管すること

## 使い方

1. GitHub Pages の URL をスマホのブラウザで開く
2. ブラウザのメニューから「ホーム画面に追加」でアプリとしてインストールできる
3. オフラインでも起動・記録できる（Service Worker でアプリ本体をキャッシュ）

## 構成

- `index.html` / `styles.css` / `app.js` — 本体（フレームワークなし、ビルド不要）
- `manifest.webmanifest` / `sw.js` / `icons/` — PWA 用ファイル
