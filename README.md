# マイツール（my-apps）

自分のための小さなツールをまとめた、モジュール式のPWAポータル。
ホーム画面に追加するのはこのポータル1つだけ。ツールはモジュールとして追加していく。

もともと Muse のスペースで作っていたツールを「正本は自分のGitHubに置く」方針で移植したもの。
コードもデータ形式もプレーンなファイルなので、特定のサービスにロックインされない。

## モジュール

| モジュール | 場所 | 内容 |
|---|---|---|
| ワークアウトログ | `workout/` | 自宅筋トレの記録。A/B/Cローテーション＋背中・脚・フットケア、進行ルール、脚の疲労感の記録 |

## モジュールの共通ルール

- データは**端末のブラウザ内（localStorage）だけ**に保存する。このリポジトリにもサーバーにも送らない
- 各モジュールは設定画面から **JSONで書き出し／読み込み** ができること（バックアップと移行のため）
- 通知・リマインダーは付けない

## 新しいツールの追加方法

1. リポジトリ直下にフォルダを作り、`index.html` 等を置く
2. ルートの `index.html` にカードを追加する
3. ルートの `sw.js` のキャッシュ対象にモジュールのファイルを追加する

## ワークアウトログのルール

- 中心は胸・腹・腕。器具は腹筋ローラー・プッシュアップバー・ゴムチューブ（＋自重、タオル）
- 週3回・1回30分、A（胸＋三頭）→ B（腕＋肩）→ C（胸＋腹）のローテーション。曜日固定なし。各グループにセットメニューが2種類あり、交互に提示される（手動で切替も可）
- 背中（D）と脚＋フットケア（E）は任意の日用でローテーションには入れない。脚メニューはマラソンの妨げにならない範囲で軽めに。**レース週とレース前日は脚メニューをやらない**
- 足のつり対策にフットケア（タオルギャザー、足指グーチョキパー、足首回し）をEに含む
- 各種目に小さなアニメーション図と1行のやり方説明を表示する
- 進行ルール：全セット目標クリア＆RPE7以下で次回 **+1回**（秒数の種目は **+5秒**）。RPE9以上か回数未達なら据え置き
- 各セッションで「脚の疲労感（1〜5）」と「次のランの感覚」を記録する
